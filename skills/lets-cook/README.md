# Let's Cook

Based entirely off [Matt Pocock's](https://github.com/mattpocock/skills) awesome and indispensible [grill-me skill](https://github.com/mattpocock/skills/tree/main/grill-me), this skill aims to reach a shared understanding of requirements through an extended interview format but extends the grill-me concept by adding a supplementary plan creation phase using [lets-serve](../lets-serve).

Often, using grill-me and transitioning directly to implementation is absolutely fine but with extended grilling sessions with many branches and extended agent exploration, you can end up with bloated context, compromising implementation quality.
