# Skills

Curated collection of personally created agent skills.

## Installation

```
pnpx skills add joshdavenport/skills --skill='*'
```

Or for individual skills:

```
pnpx skills add joshdavenport/skills --skill asana-task
pnpx skills add joshdavenport/skills --skill explain-diff
pnpx skills add joshdavenport/skills --skill explain-decision
pnpx skills add joshdavenport/skills --skill explain-html
```

## Skills

| Skill                                          | Description                                                                                                                                                       |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [asana-task](./skills/asana-task/)             | Work on a provided Asana task using the Asana MCP                                                                                                                 |
| [explain-diff](./skills/explain-diff/)         | **ALSO ADD EXPLAIN-HTML SKILL!** Create a rich, self-contained interactive HTML explanation of a code change, diff, branch, or pull request.                      |
| [explain-decision](./skills/explain-decision/) | **ALSO ADD EXPLAIN-HTML SKILL!** Create a rich, self-contained interactive HTML explanation of a proposed decision, design choice, or trade-off under discussion. |
| [explain-html](./skills/explain-html/)         | Build a rich, self-contained interactive HTML explainer page for any subject — a system, concept, process, incident, or dataset — saved as a dated HTML file      |
