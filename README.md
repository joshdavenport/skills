# Skills

Curated collection of personally created agent skills.

## Installation

```
pnpx skills add joshdavenport/skills --skill='*'
```

Or for individual skills:

```
pnpx skills add joshdavenport/skills --skill lets-cook
pnpx skills add joshdavenport/skills --skill lets-serve
```

## Skills

| Skill                              | Description                                                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| [lets-cook](./skills/lets-cook/)   | Interview relentlessly about a plan or design until shared understanding, then hand off to `lets-serve`                  |
| [lets-serve](./skills/lets-serve/) | Externalize a reached design understanding into a cold-handoff-ready plan and hand off to a clean implementation session |
